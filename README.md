# 📊 LAPD Urban Safety Intelligence Dashboard

Interactive Power BI dashboard analyzing LAPD public safety data, crime trends, spatial patterns, and victim demographics.

---

## 🛠️ Tools & Technologies Used
* **Power BI:** DAX, Data Modeling, Custom Layouts, Dynamic KPI Cards
* **Microsoft Excel:** Data Cleaning, Transformation, Relational Structuring
* **GitHub:** Portfolio Presentation & Documentation

---

## 📈 Dashboard Overview & Visualizations

### 1. Operational Overview
Tracks high-level incident volumes, active case statuses, and historical crime trends.

---

### 2. Tactical & Situational Intelligence
Breaks down crime hotspots by area, most common crime types, top premise types, and weapon involvement.
![Tactical Intelligence](JIBRIL%20DASHBOARD%202.PNG)

### 3. Victim Demographics
Analyzes overall victim distribution by gender and ethnic breakdown for target safety initiatives.
